# Подключение бесплатного ИИ (необязательно)

Аудит полностью работает без ИИ. Модель нужна там, где эвристика слаба: понять,
о чём канал на самом деле, и отличить полезный поток от «успешного успеха».

## Вариант A. Groq Cloud (рекомендуется)

Бесплатный ключ без привязки карты, открытые модели (Llama 3.x), лимит около
30 запросов в минуту — при батчах по 15 чатов этого хватает с запасом.

1. Зайти на <https://console.groq.com>, создать API-ключ.
2. Прописать в `.env`:

```
TGAUDIT_AI_PROVIDER=groq
TGAUDIT_AI_KEY=gsk_...
TGAUDIT_AI_MODEL=llama-3.3-70b-versatile
```

3. `python -m tgaudit score`

## Вариант B. Google AI Studio (Gemini Flash)

Бесплатный ключ, щедрые лимиты (порядка 10–15 запросов в минуту).

```
TGAUDIT_AI_PROVIDER=gemini
TGAUDIT_AI_KEY=AIza...
TGAUDIT_AI_MODEL=gemini-2.0-flash
```

## Вариант C. Любой openai-совместимый сервис

Подойдёт и локальная модель (Ollama, LM Studio) — тогда наружу не уходит ничего.

```
TGAUDIT_AI_PROVIDER=openai-compatible
TGAUDIT_AI_BASE_URL=http://localhost:11434/v1
TGAUDIT_AI_MODEL=llama3.1
TGAUDIT_AI_KEY=ollama
```

## Вариант D. Без ключей, руками

`python -m tgaudit report` кладёт в `out/batches/` файлы по 20–30 чатов с уже
вписанным промптом. Открываете `batch_01.md`, копируете целиком в ChatGPT, Claude
или Gemini, получаете разбор. Файлы весят килобайты и влезают в контекст любой
бесплатной модели.

Промпт можно поправить под себя: `prompts/batch_analysis_ru.md`.

## Приватность

- Личные переписки **не отправляются** во внешний ИИ. Чтобы разрешить:
  `TGAUDIT_AI_INCLUDE_DMS=1` (подумайте дважды).
- Наружу уходит только то, что видно в блоке чата: название, тип, счётчики и
  обрезанные до 300 символов тексты последних сообщений.
- Локальная модель через `openai-compatible` не отправляет наружу ничего.

## Как ИИ влияет на вердикт

Никак — и это сознательно. Ответ модели пишется в поля `ai_bucket`, `ai_topic`,
`ai_reason`, а итоговая корзина остаётся за прозрачной эвристикой. Если мнения
расходятся, в причинах появляется строка:

```
ИИ считает иначе (unsubscribe): сплошная реклама курсов
```

Такие расхождения удобно просматривать первыми: обычно именно там интересные случаи.

## Если ИИ недоступен

Нет ключа, кончились лимиты, нет сети — этап 3 напишет предупреждение и посчитает
всё на эвристике. Аудит не ломается:

```
  ⚠ ИИ пропущен: Лимит запросов к groq: rate_limit_exceeded
Скоринг готов (312 чатов):
  Оставить                  84  (26.9 %)
```
