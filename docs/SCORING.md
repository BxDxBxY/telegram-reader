# Как считается балл и вердикт

Скоринг детерминированный: одни и те же данные всегда дают один и тот же результат,
а каждая составляющая записывается в причины вердикта. Ничего не происходит «потому
что нейросеть так решила».

Код: `tgaudit/heuristics.py` (этап 1) и `tgaudit/scoring.py` (этап 3).

## Этап 1: фильтрация по метаданным

Решение принимается без чтения сообщений — цель отсеять 40–50 % чатов.

| Условие | Решение |
| --- | --- |
| служебный аккаунт Telegram (777000 и т. п.) | `keep`, не трогать никогда |
| метка Telegram `scam` / `fake` | `drop` |
| чат закреплён вами | `keep` |
| личная переписка (без `--include-dms`) | `keep`, содержимое не читается |
| нет активности больше года | `drop` |
| нет активности больше `TGAUDIT_DEAD_DAYS` (180 дней) | `drop` |
| бот без использования больше 90 дней | `drop` |
| в архиве и молчит больше 90 дней | `drop` |
| всё остальное | `sample` — нужен срез сообщений |

## Этап 3: балл 0–100

Старт — 50 баллов, дальше плюсы и минусы.

**Свежесть**

| Последняя активность | Баллы |
| --- | ---: |
| меньше недели | +15 |
| меньше месяца | +8 |
| 1–3 месяца | 0 |
| 3–6 месяцев | −12 |
| 6–12 месяцев | −25 |
| больше года | −40 |

**Ваше поведение** (самый честный сигнал полезности)

| Признак | Баллы |
| --- | ---: |
| чат закреплён | +25 |
| есть непрочитанные упоминания вас | +10 |
| читаете вовремя (0 непрочитанных, чат живой) | +6 |
| уведомления выключены | −8 |
| лежит в архиве | −10 |
| больше 300 непрочитанных | −6 |
| больше 1000 непрочитанных | −12 |

**Метки Telegram:** `scam`/`fake` — −45, `verified` — +5.

**Содержимое среза** (этап 2). Все штрафы этой группы умножаются на
«доверие к срезу» = `min(1, число сообщений / 8)`: по двум сообщениям приговор
не выносится.

| Признак | Баллы |
| --- | ---: |
| реклама/мусор в ≥50 % постов | −30 |
| реклама в ≥30 % постов | −18 |
| реклама в ≥15 % постов | −8 |
| ≥2 сообщения со скамом | −20 |
| ≥2 сообщения с инфоцыганством | −12 |
| больше 70 постов в неделю (флуд) | −12 |
| реже одного поста в две недели | −8 |
| ≥70 % постов — репосты | −10 |
| короткие посты из одних ссылок | −8 |

**Дубли.** Каналы группируются по теме (словарь в `TOPIC_KEYWORDS`) или по общему
редкому слову в названии. Внутри группы флагманом становится чат с лучшим баллом,
остальные получают −15. При этом дублирование само по себе не отправляет в отписку:
полезный, но повторяющийся канал уходит максимум в архив.

## Корзины

| Балл | Корзина |
| --- | --- |
| ≥ 60 | Оставить |
| 35–59 | В архив |
| < 35 | Отписаться / удалить |

Личные переписки никогда не попадают в «отписаться» — максимум «в архив»,
решение остаётся за вами.

## Как подкрутить под себя

- Пороги «мёртвого» чата: `TGAUDIT_DEAD_DAYS`, `TGAUDIT_STALE_DAYS` в `.env`
  или флаг `--dead-days` у команды `triage`.
- Границы корзин: `ScoringConfig(keep_threshold=..., archive_threshold=...)`
  в `tgaudit/scoring.py`.
- Словари рекламы и скама: `PATTERN_GROUPS` в `tgaudit/heuristics.py`. Добавьте
  формулировки, которые достали лично вас, — это обычные регулярные выражения.
- Темы для поиска дублей: `TOPIC_KEYWORDS` там же.

После правок пересчёт бесплатный и без сети:

```bash
python -m tgaudit triage && python -m tgaudit score && python -m tgaudit report
```
